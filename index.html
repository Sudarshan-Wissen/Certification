General instructions

  1. The exam has a fixed number of multiple-choice questions, each with a single best answer.
  2. A countdown timer is shown at the top of the screen at all times. The exam is submitted automatically when time expires.
  3. Use Save & Next to record your answer and move to the next question, or Mark for Review & Next to flag a question for a second look without losing your place.
  4. Clear Response removes your selected answer for the current question.
  5. Use the Question Palette on the right to jump to any question at any time before submitting.
  6. You may submit the test early at any time using Submit Test.

Bring your own question bank

Preparing for CCDV, or any other exam this console doesn't ship questions for? Convert your exam's PDF into a JSON file with the recipe below, upload it, and take a full mock exam or drill it in Practice Mode, the same way as the built-in CCAR-F sets.

How to convert a PDF question paper to JSON

  1. Open a fresh conversation with Claude, or any LLM that accepts document uploads.
  2. Paste the prompt below into the chat.
  3. Attach your exam's PDF (and its answer key, if it's a separate document).
  4. Copy the JSON the model returns and save it as a .json file.
  5. Upload that file below.
You will convert a multiple-choice exam question paper (and its answer key, if provided separately) into a JSON array for a practice-test app.

Read the attached document(s) and output ONLY a JSON array (no markdown code fences, no commentary before or after) where each element is an object with exactly these fields:

{
  "q": "The full question text, exactly as written",
  "opts": ["Option A text", "Option B text", "Option C text", "Option D text"],
  "ans": 0,
  "dom": "Short topic or domain name for this question",
  "why": "A one to two sentence explanation of why the correct answer is correct"
}

Rules:
- "opts" always has exactly 4 items, in their original order, with the "A.", "B." etc. prefixes removed.
- "ans" is the zero-indexed position of the correct option: 0 for the first option, 1 for the second, 2 for the third, 3 for the fourth.
- "dom" is a short, consistent label for the topic or domain the question belongs to, such as a section heading from the exam blueprint. Reuse the same label across every question in that domain so they group together correctly.
- "why" briefly justifies the correct answer, using the answer key's rationale if one is given, or accurate reasoning of your own if not.
- Include every question from the document, in its original order.
- The output is a single valid JSON array and nothing else. Do not wrap it in markdown backticks.
